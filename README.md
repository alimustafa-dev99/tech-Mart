# 🛒 Tech Mart — E-Commerce Website

**Tech Mart** is a full-stack e-commerce web application built using Object-Oriented PHP and MySQL. The project focuses on dynamic website functionality, database integration, user authentication, and administrative management.

The application uses a structured backend with controllers and model/query components to organize application logic and database operations.

**[Visit Tech Mart](https://techmart11.epizy.com/)**

## ✨ Key Features

- **E-Commerce Interface** — An online shopping interface for browsing products.
- **User Authentication** — Login functionality for user access.
- **Admin Panel** — A dedicated administrative interface for managing website operations.
- **Object-Oriented PHP** — Backend functionality organized using object-oriented programming principles.
- **Controller-Based Structure** — Controllers organize application logic and request handling.
- **Model and Query Components** — Structured components for database-related operations.
- **MySQL Database Integration** — Persistent data storage and retrieval.
- **Dynamic PHP Pages** — Server-side rendering and application functionality.

## 🏗️ Backend Architecture

The project uses a controller and model/query-based structure to organize backend responsibilities.

- **Controllers:** Handle application requests and coordinate application logic.
- **Model/Query Components:** Organize database operations and data retrieval.
- **PHP Backend:** Processes application logic on the server.
- **MySQL:** Stores and manages application data.

This structure helps separate responsibilities and makes the codebase easier to maintain than placing all application logic in a single file.

## 🚀 Getting Started

### Prerequisites

- [XAMPP](https://www.apachefriends.org/)
- A web browser
- Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the actual URL of your Tech Mart repository.

**2. Move the project**

Place the project folder inside your XAMPP installation directory:

```text
C:\xampp\htdocs\
```

**3. Start Apache and MySQL**

Open the XAMPP Control Panel and start both services.

**4. Configure the database**

- Open [phpMyAdmin](http://localhost/phpmyadmin/).
- Create the database required by the project.
- Import the provided SQL file, if included in the repository.
- Configure the database connection using your local MySQL credentials.

Refer to the project's source code for the actual database name, SQL file, and connection configuration.

**5. Run the application**

Open the project in your browser:

```text
http://localhost/YOUR_PROJECT_FOLDER/
```

Replace `YOUR_PROJECT_FOLDER` with the actual folder name.

## 🔐 Security Notes

- Test authentication and administrative access controls before deploying changes.
